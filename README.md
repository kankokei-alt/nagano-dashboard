# 長野県 観光分析ダッシュボード

長野県観光機構・地域DMO・観光協会の方が、公的統計から長野県観光の「いま」と「これから」をつかむためのダッシュボードです。

- **データに詳しくない人が、迷わず読める**ことを最優先にしています。各ページの最初にある「ここがポイント」に要点を書き、数字やグラフは絞っています。
- 目的ごとにページ（タブ）を分けています。
- 地図は国土数値情報の正確な行政区域ポリゴンで描きます。外部の地図タイルを使わないので、庁内ネットワークでも表示できます。

## ページ構成

| ページ | 見る人の問い | 主なデータ |
|---|---|---|
| 🗾 長野県を俯瞰する | 県全体でいま何が起きている？ 訪日客はこの先どうなりそう？ | 宿泊旅行統計、観光入込客統計、JNTO 訪日外客統計 |
| 🔍 市町村を深掘りする | うちのまちのどのエリアが伸びている？（例: 長野市の中心市街地・松代・戸隠） | 観光地利用者統計、デジタル観光統計、国勢調査の小地域境界 |
| 🤝 広域で連携する | 圏域の中で集中している所・周遊の余地がある所は？ | 観光地利用者統計、デジタル観光統計 |
| 📈 稼働率予測（ベータ版） | この先12か月の客室稼働率は上がる？下がる？（宿の種類別） | 宿泊旅行統計、気象庁、JNTO、祝日・連休、イベント |
| 📚 データについて | このデータはどこから来ている？ | ― |

## 動かし方

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

# データの準備（取得済みのものは data/processed/ に入っています）
python pipelines/fetch_boundaries.py   # 行政区域ポリゴン（国土数値情報 N03）
python pipelines/build_calendar.py     # 祝日・連休カレンダー
python pipelines/shukuhaku.py          # 宿泊旅行統計（観光庁の推移表。毎月更新）
python pipelines/shukuhaku_detail.py   # 宿泊旅行統計の内訳（県内外別・国籍別・県内5エリア。年1回）
python pipelines/nagano_pref.py irikomi    # 長野県 観光入込客統計（年1回）
python pipelines/nagano_pref.py riyousha   # 長野県 観光地利用者統計調査（年1回）
python pipelines/jnto.py               # JNTO 訪日外客統計（国籍×月。毎月）
python pipelines/weather.py            # 気象庁 主要地点の月別の気温・降雪・積雪（毎月）
python pipelines/forecast.py           # 稼働率予測を作り直す（上の3つを更新したあと。1分ほど）

streamlit run app/main.py
```

e-Stat API を使う取得には、アプリケーションIDを環境変数で渡します（**リポジトリには書かない**）。

```bash
export ESTAT_APP_ID=xxxxxxxx
python pipelines/estat.py search 宿泊旅行統計調査
```

## フォルダ


## データの取り込み状況

一覧は `config/datasets.csv`（アプリの「データについて」ページにも表示）を参照してください。

### 取り込みについてのメモ

- **宿泊旅行統計調査**: e-Stat の API には 2016年分の表しかない（2026年10月時点）ため、観光庁のページの Excel を直接読んでいます。
  - 推移表 … 都道府県×月の延べ宿泊者数・外国人・客室稼働率（2011年1月〜）
  - 年の確定値（2007〜2025年の各年）… 長野県の県内/県外別（第9表, 2010年〜）と国籍別の外国人（参考第1表, 2009年〜）
    - 県内/県外別は 2011年以降、推移表の合計とすべての月で一致することを確認。2010年だけは「従業者10人以上の施設」の集計です。
    - 国籍別は「従業者10人以上の施設」の集計。国・地域の区分は 13→16→19→21 と年によって増えています。
  - 広域市町村（130区分）別の参考表 … 長野県内5エリア（東部・南部・西部・長野・北信）×月（2021年〜）。合計は県全体と一致。
  - 2026年1月分から調査の層化基準が「従業者数」→「客室数」に変わったので、2026年の前年比には見直しの影響が含まれることがあります（画面にも注記）。
- **観光入込客統計・観光地利用者統計調査**: 県の観光課のページ（PDF）と、**統計ステーションながの**（tokei.pref.nagano.lg.jp, Excel）の両方から取っています。
  - 利用者統計の観光地別・月別の明細は 2011〜2025年。2016年以降は統計ステーションながのの Excel（利用者統計=8998）、
    2015年以前は PDF を `pdfplumber` で読み取り。各年の合計が県の公表値と 0.5% 以内で一致する年だけを採用しています（2010年は合う表が読めず除外）。
    2022年以降の Excel には観光地コード（`spot_code` = 市町村コード-観光地コード）があり、同じ名前の観光地には過去の年にも付けています。
  - 観光地別の年次推移は 2010〜2025年（最新の PDF の年次推移表）。
  - 入込客統計は 2010〜2025年の16年分を PDF から。各年の見出しの数字と一致することを確認。統計ステーションながのの Excel 版（入込客統計=8999, 2016〜2019年）は中身が同じなので照合だけに使っています
    （サイトの「平成29年」の項目には平成30年のファイルが置かれているため、年は Excel の表題から判定）。
    2010〜2015年はビジネス目的、2017・2018年は入込客数が「参考値」とされています。
  - 統計ステーションながのは、一覧をページ内の Ajax（`admin-ajax.php` の `search_tokei_list`）で読み込み、ダウンロードは
    `statistics-info/statistics_download?pid=…&type=excel`。既定の Python の User-Agent だと 403 になるので UA を付けています。

- **訪日外客統計（JNTO）**: 統計ページの「国籍/月別 訪日外客数（2003年～）」の Excel を取得（リンクはページから探す）。
  - 年ごとのシート。最新年は暫定値で、**斜体の値は推計値**（百人単位に丸め、地域計なし）。書式から判定して `status` に残しています。
  - 照合: 各年の「総数」の月の合計＝シートの累計（年計）列（推計値を含む年は丸めの分 ±50人まで）、確定年は「年別 訪日外客数」PDF の値とも一致。2003〜2025年・2026年1〜8月のすべてが一致（`data/processed/checks/jnto.csv`）。
  - 俯瞰ページでは、長野県の国籍別宿泊者の構成（最新年）で全国の国別の伸びを重みづけした「長野の客層に合わせた伸び」も出しています。
- **過去の気象データ（気象庁）**: 「過去の気象データ検索」の地点×年の「月ごとの値」ページ（気象台など=monthly_s1、アメダス=monthly_a1）を読みます。地点は `config/weather_stations.csv`。
  - 記号: `)` 準正常値は使う、`]` 資料不足値は使わない、`--`（現象なし）は降雪・積雪を 0。
  - 照合: 年平均気温（月平均の平均と ±0.15℃）、寒候年（前年8月〜7月）の降雪量の合計・最深積雪を「年ごとの値」ページと照合。
    年ごとの値が資料不足の冬（軽井沢2010、白馬2016・2018、野沢温泉2025（最深積雪）、菅平2013）は使っていません（`data/processed/checks/weather.csv`）。
- **稼働率予測（`pipelines/forecast.py`）**: 全体・旅館・リゾートホテル・ビジネスホテル・シティホテルの5系列。
  - ① 季節パターン … 直近12か月の平均＋季節の山・谷（直近3つの平常年）。夏の山が2010年代より小さくなっているため、古い年まで平均しないようにしています。
  - ② 手がかり入り … ①を、前年同月のずれ・休日数・3連休・積雪（白馬・野沢温泉・菅平）・全国の訪日客の伸び×前年の外国人比率・イベント・旅行支援・新幹線開業・直近3か月の勢いでリッジ回帰により補正。
  - 検証は予測時点を1か月ずつずらすローリング方式（2015〜2020年1月、2024〜2026年の実績、91回）。先の月の積雪は平年並み、未公表の訪日客は直近3か月の伸びが続くとみなし、実際の予測と同じ条件にしています。コロナ期間（events.csv の covid）にかかる月は学習・検証とも除外。
  - 結果（1〜12か月先の平均のずれ）: 全体 ①1.60pt／②1.76pt、旅館 ①2.00／②2.32、リゾートホテル ①3.01／②3.26、ビジネスホテル ①2.19／②2.39、シティホテル ①3.63／②3.49。
    **②が①を上回ったのはシティホテルだけ**なので、ほかの4系列は①で予測しています（2026年10月時点）。
  - 予測の幅は、検証の誤差の 10〜90% 点（1〜3／4〜6／7〜12か月先で別々）。

## 出典

- 行政区域: 国土数値情報（行政区域データ N03, 2020年1月1日時点）国土交通省 … [niiyz/JapanCityGeoJson](https://github.com/niiyz/JapanCityGeoJson) が GeoJSON に変換したものを取得して加工
- 祝日: 内閣府「国民の祝日」（`jpholiday` パッケージ経由）
- 宿泊: 観光庁「宿泊旅行統計調査」（推移表）
- 観光入込客数・観光消費額: 長野県「観光入込客統計」（観光庁「観光入込客統計に関する共通基準」に基づく）
- 観光地別の利用者数: 長野県「観光地利用者統計調査」
- 訪日外客数: 日本政府観光局（JNTO）「訪日外客統計」
- 気温・降雪・積雪: 気象庁「過去の気象データ」
